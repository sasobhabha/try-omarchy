<h1 align="center">Try Omarchy</h1>

<h3 align="center">Omarchy inside Apple's Ecosystem.</h3>

Try Omarchy is an iPhone/iPad app that runs stock Omarchy in a slow virtual machine. A bluetooth keyboard is required. 

Third party components keep their own licenses; see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). The Omarchy mark comes from the [official brand kit](https://omarchy.org/brand/) and remains subject to Omarchy's trademark rights.
